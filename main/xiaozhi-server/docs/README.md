## 📂 目录详解

### 00-项目文档

项目的原始文档，包含：

- 部署指南（本地、Docker、全栈）
- 各类服务集成文档（Home Assistant、阿里云短信、Fish Speech等）
- 固件编译和设置
- 性能测试工具

### 01-当前文档

当前正在维护的核心文档，包含：

- 最新的协议规范（ESP32、App）
- 系统架构说明
- API参考文档
- 配置和使用指南
- 详细的技术分析文档

### 02-已完成

已完成的开发任务归档，按类型分类：

- **协议升级**：v5.0→v5.2、App v2.2→v2.5等
- **数据库优化**：迁移脚本、用户管理实现等
- **Bug修复**：连接问题、编码错误、seq_id修复等
- **代码分析**：代码一致性检查、错误码统一等
- **功能开发**：人脸识别、智能门锁、AI功能等
- **已废弃**：旧版本协议文档

### 03-功能开发参考

功能开发的参考文档，包含：

- 实施指南
- 协议规范
- 实现总结

### 04-本地预览功能

本地预览功能的完整文档集合，包含：

- 方案对比
- 实施计划和完成报告
- 使用指南
- MCP方案设计

## 📝 文档维护规范

### 新增文档

- **当前开发文档** → `01-当前文档/`
- **功能开发参考** → `03-功能开发参考/`
- **特定功能集合** → 创建新的编号文件夹（如 `05-xxx功能/`）

### 文档归档

任务完成后，将相关文档移至 `02-已完成/` 对应分类：

- 协议相关 → `协议升级/`
- 数据库相关 → `数据库优化/`
- Bug修复 → `Bug修复/`
- 代码重构/分析 → `代码分析/`
- 新功能开发 → `功能开发/`
- 废弃内容 → `已废弃/`

### 文档更新

- 重大更新需在文档头部标注更新日期
- 协议变更需更新版本号
- 同步更新本 README 的快速导航链接
