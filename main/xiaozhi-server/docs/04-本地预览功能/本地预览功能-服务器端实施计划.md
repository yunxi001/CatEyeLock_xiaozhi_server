## 1. 功能概述

### 1.1 目标

实现服务器端对本地预览功能的支持，允许用户通过**语音命令**控制 ESP32 的本地预览功能。

### 1.2 功能范围

**本次实施（Phase 1 - 基础功能）**：

- ✅ 语音命令识别（通过插件系统）
- ✅ WebSocket 命令转发到 ESP32
- ✅ 处理 ESP32 响应
- ✅ 语音反馈

**暂不实施**：

- ❌ 互斥检查（ESP32 端已实现）
- ❌ 状态管理（后续 Phase 2）
- ❌ HTTP API 接口（APP 端控制，后续实施）

### 1.3 用户场景

**场景1：启动本地预览**

```
用户：显示监控画面
ESP32：采集语音 → 发送到服务器
服务器：识别意图 → 发送命令到 ESP32
ESP32：启动本地预览 → 返回成功
服务器：语音反馈 "已打开本地预览"
```

**场景2：停止本地预览**

```
用户：关闭监控画面
ESP32：采集语音 → 发送到服务器
服务器：识别意图 → 发送命令到 ESP32
ESP32：停止本地预览 → 返回成功
服务器：语音反馈 "已关闭本地预览"
```

## 2. 技术方案

### 2.1 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│                        服务器端                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 语音输入（ESP32 → 服务器）                               │
│     ↓                                                       │
│  2. ASR 服务（语音转文字）                                   │
│     ↓                                                       │
│  3. 意图识别（intent_llm.py）                                │
│     - LLM 分析用户意图                                       │
│     - 匹配到 control_local_preview 插件                      │
│     ↓                                                       │
│  4. 插件执行（control_local_preview.py）                     │
│     - 构建 WebSocket 命令                                    │
│     - 发送到 ESP32                                           │
│     - 等待响应                                               │
│     ↓                                                       │
│  5. 处理响应                                                 │
│     - 成功：生成语音反馈                                     │
│     - 失败：生成错误提示                                     │
│     ↓                                                       │
│  6. TTS 服务（文字转语音）                                   │
│     ↓                                                       │
│  7. 语音输出（服务器 → ESP32）                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 核心组件

#### 2.2.1 插件文件

**文件路径**：`main/xiaozhi-server/plugins_func/functions/control_local_preview.py`

**职责**：

- 定义 function schema（让 LLM 识别触发词）
- 实现控制逻辑（发送 WebSocket 命令）
- 处理 ESP32 响应
- 生成语音反馈文本

#### 2.2.2 WebSocket 命令格式

**发送到 ESP32**：

```json
{
  "type": "local_preview",
  "action": "start" // 或 "stop"
}
```

**ESP32 响应（成功）**：

```json
{
  "type": "local_preview",
  "action": "start",
  "status": "success"
}
```

**ESP32 响应（失败）**：

```json
{
  "type": "local_preview",
  "action": "start",
  "status": "error",
  "error": "Camera not available" // 或其他错误信息
}
```

## 3. 实施步骤

### 步骤 1：创建插件文件

**文件**：`main/xiaozhi-server/plugins_func/functions/control_local_preview.py`

**内容要点**：

1. **导入依赖**
   - `register_function` 装饰器
   - `ActionResponse`、`Action` 枚举
   - 日志模块

2. **定义 Function Schema**

   ```python
   CONTROL_LOCAL_PREVIEW_DESC = {
       "type": "function",
       "function": {
           "name": "control_local_preview",
           "description": "控制本地预览功能的开启或关闭。当用户说'显示监控画面'、'打开监控画面'、'让我看看门口'、'打开本地预览'、'屏幕显示摄像头'、'关闭监控画面'、'隐藏监控画面'、'关闭本地预览'、'关闭屏幕显示'等时调用此函数",
           "parameters": {
               "type": "object",
               "properties": {
                   "action": {
                       "type": "string",
                       "enum": ["start", "stop"],
                       "description": "操作类型：start表示启动本地预览，stop表示停止本地预览"
                   }
               },
               "required": ["action"]
           }
       }
   }
   ```

3. **实现插件函数**
   - 参数：`conn`（连接对象）、`action`（start/stop）
   - 逻辑：
     - 构建 WebSocket 命令
     - 发送到 ESP32（通过 `conn.send_json()`）
     - 等待响应（需要实现响应等待机制）
     - 根据响应生成反馈文本
   - 返回：`ActionResponse` 对象

4. **注册插件**
   ```python
   @register_function("control_local_preview", CONTROL_LOCAL_PREVIEW_DESC, ToolType.SYSTEM_CTL)
   async def control_local_preview(conn, action: str):
       # 实现逻辑
   ```

### 步骤 2：实现 WebSocket 命令发送

**关键点**：

1. **发送命令**

   ```python
   message = {
       "type": "local_preview",
       "action": action
   }
   await conn.send_json(message)
   ```

2. **等待响应**（需要实现响应等待机制）
   - 方案A：使用 `asyncio.Future` + 超时
   - 方案B：使用 `asyncio.wait_for()` + 事件
   - 方案C：参考现有的命令响应机制（如监控模式）

3. **超时处理**
   - 超时时间：10 秒
   - 超时后返回错误

### 步骤 3：处理 ESP32 响应

**响应处理逻辑**：

1. **成功响应**
   - `status == "success"`
   - 生成语音反馈：
     - 启动成功："已打开本地预览"
     - 停止成功："已关闭本地预览"

2. **失败响应**
   - `status == "error"`
   - 根据 `error` 字段生成提示：
     - `"Camera not available"` → "摄像头暂时不可用"
     - `"Monitor mode active"` → "监控模式正在运行，无法启动本地预览"
     - `"Face recognition active"` → "人脸识别正在进行，请稍后再试"
     - `"System error"` → "系统错误，请稍后再试"

3. **超时处理**
   - 生成提示："操作超时，请稍后再试"

### 步骤 4：返回 ActionResponse

**返回类型**：

- **成功**：`ActionResponse(action=Action.RESPONSE, result="操作成功", response="已打开本地预览")`
- **失败**：`ActionResponse(action=Action.RESPONSE, result="操作失败", response="摄像头暂时不可用")`

**Action 类型说明**：

- `Action.RESPONSE`：直接语音反馈（不经过 LLM）
- `Action.REQLLM`：调用 LLM 生成自然语言回复（可选）

### 步骤 5：测试验证

**测试场景**：

1. **启动本地预览**
   - 语音输入："显示监控画面"
   - 预期：ESP32 启动本地预览，语音反馈"已打开本地预览"

2. **停止本地预览**
   - 语音输入："关闭监控画面"
   - 预期：ESP32 停止本地预览，语音反馈"已关闭本地预览"

3. **触发词变体测试**
   - "打开本地预览"
   - "让我看看门口"
   - "屏幕显示摄像头"
   - 预期：都能正确识别为启动命令

4. **错误处理测试**
   - 监控模式运行时启动本地预览
   - 预期：语音反馈"监控模式正在运行，无法启动本地预览"

5. **超时测试**
   - ESP32 无响应
   - 预期：10 秒后语音反馈"操作超时，请稍后再试"

## 6. 风险和注意事项

### 6.1 技术风险

| 风险                         | 影响               | 缓解措施                                    |
| ---------------------------- | ------------------ | ------------------------------------------- |
| WebSocket 响应等待机制不完善 | 可能导致超时或阻塞 | 参考现有命令响应机制，使用 asyncio 超时控制 |
| LLM 意图识别不准确           | 触发词识别失败     | 在 function description 中提供足够的示例    |
| ESP32 响应格式不一致         | 解析失败           | 添加容错处理，记录详细日志                  |

### 6.2 注意事项

1. **异步处理**
   - 插件函数必须是 `async def`
   - 使用 `await` 等待 WebSocket 响应

2. **错误处理**
   - 捕获所有异常，避免插件崩溃
   - 返回友好的错误提示

3. **日志记录**
   - 记录关键步骤，便于调试
   - 使用 `logger.bind(tag=TAG)` 统一日志格式

4. **兼容性**
   - 确保与现有插件系统兼容
   - 遵循 `ActionResponse` 返回规范
