# 本地预览功能 - 快速使用指南

## 📋 功能简介

本地预览功能允许用户通过**语音命令**控制 ESP32 的 LCD 屏幕显示摄像头画面，无需通过 APP 即可快速查看门口情况。

**特点**：

- 🎤 语音控制，解放双手
- 📺 本地显示，无网络延迟
- 🔄 自动识别多种说法
- ⚡ 快速响应，即说即显

---

## 🚀 快速开始

### 用户使用

#### 启动本地预览

对着设备说：

- "显示监控画面"
- "打开监控画面"
- "让我看看门口"
- "打开本地预览"
- "屏幕显示摄像头"

**预期效果**：

- ESP32 的 LCD 屏幕开始显示摄像头画面
- 语音反馈："已打开本地预览"

#### 停止本地预览

对着设备说：

- "关闭监控画面"
- "隐藏监控画面"
- "关闭本地预览"
- "关闭屏幕显示"

**预期效果**：

- ESP32 的 LCD 屏幕停止显示摄像头画面
- 语音反馈："已关闭本地预览"

## ⚠️ 常见问题

### Q1: 说了触发词但没有反应？

**可能原因**：

1. 设备未连接到服务器
2. 麦克风未正常工作
3. 语音识别失败

**解决方法**：

1. 检查设备连接状态
2. 检查麦克风是否正常
3. 查看服务器日志

### Q2: 提示"监控模式正在运行"？

**原因**：本地预览与监控模式互斥，不能同时运行。

**解决方法**：先关闭监控模式，再启动本地预览。

### Q3: 提示"摄像头暂时不可用"？

**可能原因**：

1. 摄像头硬件故障
2. 摄像头被其他功能占用
3. 系统资源不足

**解决方法**：

1. 检查摄像头硬件
2. 等待其他功能释放摄像头
3. 重启设备

### Q4: 提示"操作超时"？

**可能原因**：

1. ESP32 未响应
2. 网络延迟过高
3. ESP32 端未实现功能

**解决方法**：

1. 检查 ESP32 连接状态
2. 检查网络质量
3. 确认 ESP32 端已实现功能

## 🔍 错误提示对照表

| 语音反馈                           | 原因                   | 解决方法           |
| ---------------------------------- | ---------------------- | ------------------ |
| 摄像头暂时不可用                   | 摄像头硬件问题或被占用 | 检查硬件，等待释放 |

## 📊 功能对比

### 本地预览 vs 监控模式

| 特性     | 本地预览        | 监控模式     |

## 🎯 使用建议

### 适用场景

✅ **推荐使用本地预览**：

- 在家时快速查看门口
- 等待访客到来
- 检查门口是否有人
- 临时查看摄像头画面

❌ **不推荐使用本地预览**：

- 外出时远程查看（使用监控模式）
- 需要录像功能（使用监控模式）
- 需要双向语音（使用监控模式）

### 使用技巧

1. **快速启动**：直接说"显示监控画面"，最简洁
2. **自然表达**：可以用自然语言，如"让我看看门口"
3. **及时关闭**：查看完毕后及时关闭，节省电量
4. **避免冲突**：不要在监控模式运行时启动本地预览
