# 智能门锁项目开发文档

## 一、项目概述

本项目基于 xiaozhi-esp32-server 扩展，实现智能猫眼门锁功能，包含两大模块：

1. **监控模式** - ESP32 实时音视频传输到 App，支持双向对讲
2. **人脸识别** - ESP32 采集人脸图像，服务器识别后控制开门

## 四、工作模式

### 正常模式
```
ESP32 音频 → Server → ASR → LLM → TTS → ESP32
ESP32 状态(forward) → Server(存储) → App
App 控制(forward) → Server → ESP32
```

### 监控模式
```
ESP32 音频/视频 → Server → App（实时转发，不解析）
App 音频 → Server → ESP32（双向对讲）
App 控制命令 → Server → ESP32
```

## 五、通信协议

### 5.1 连接方式

| 端 | WebSocket 端点 |
|----|----------------|
| ESP32 | `ws://server:port/ws/xiaozhi` |
| App | `ws://server:port/ws/app` |

### 5.2 App 认证
```json
// App 发送
{"type": "hello", "device_id": "AA:BB:CC:DD:EE:FF", "client_type": "app"}

// 服务器响应
{"type": "hello", "status": "ok", "device_info": {"online": true, "mode": "normal"}}
```

### 5.3 模式切换
```json
// 启动监控
{"type": "system", "command": "start_monitor"}

// 停止监控
{"type": "system", "command": "stop_monitor"}
```

### 5.4 BinaryProtocol2 格式（16字节头部）
```
version(2) | type(2) | reserved(4) | timestamp(4) | payload_size(4) | payload...
```
- 音频：type=0, reserved=0
- 视频：type=0, reserved=(width<<16)|height

### 5.5 人脸识别请求
```json
// ESP32 → 服务器
{"type": "face_recognition", "action": "recognize", "image": "<BinaryProtocol2 base64>"}

// 服务器 → ESP32
{"type": "face_recognition", "result": "known", "person": {"id": 1, "name": "张三"}, "access": {"granted": true, "action": "open_door"}}
```
