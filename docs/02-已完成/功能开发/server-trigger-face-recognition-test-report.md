## 六、问题记录

### 发现的问题

**问题1：配置文件编码警告**

- 描述：在Windows环境下，需要显式指定UTF-8编码读取YAML文件
- 影响：如果不指定编码，可能导致中文注释读取失败
- 状态：已知问题，不影响功能
- 建议：在配置加载代码中统一使用 `encoding='utf-8'`

**问题2：face_recognition_models 弃用警告**

- 描述：`pkg_resources is deprecated as an API`
- 影响：不影响功能，但会显示警告信息
- 状态：第三方库问题，等待库更新
- 建议：暂时忽略，或考虑固定 Setuptools 版本
