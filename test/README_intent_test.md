# 访客意图识别测试工具使用说明

## 概述

本测试工具用于验证基于大语言模型的访客交互功能，包括：

- 语音转文字（ASR）
- LLM意图识别
- 意图分类（快递/访客/求助等）
- 小程序通知推送

## 测试文件说明

### 1. `test_visitor_intent_recognition.py` - 完整测试套件

功能最全面的测试脚本，包含5个预设测试场景：

| 场景名称   | 意图类型    | 测试内容           |
| ---------- | ----------- | ------------------ |
| 快递员送货 | delivery    | 快递送达、留言转告 |
| 朋友拜访   | visit       | 熟人拜访、约定见面 |
| 推销人员   | sales       | 推销产品、拒绝服务 |
| 物业维修   | maintenance | 物业检查、维修服务 |
| 紧急求助   | emergency   | 邻居求助、紧急情况 |

**使用方法：**

```bash
# 运行所有测试场景
python test_visitor_intent_recognition.py

# 指定服务器地址
python test_visitor_intent_recognition.py --server ws://192.168.1.100:8000/xiaozhi/v1/

# 只运行单个场景
python test_visitor_intent_recognition.py --scenario "快递员送货"

# 自定义设备ID
python test_visitor_intent_recognition.py --device-id "AA:BB:CC:DD:EE:FF"
```

### 2. `quick_test_intent.py` - 快速测试脚本

简化版测试工具，用于快速验证基本功能。

**使用方法：**

```bash
python quick_test_intent.py
```

## 测试场景详解

### 场景1: 快递员送货

**对话流程：**

1. AI: "您好，请问您找谁？"
2. 访客: "你好，我是快递员，有个包裹要送给张先生"
3. AI: "好的，请问是什么快递公司的？"
4. 访客: "顺丰快递，麻烦帮我转告一下，包裹比较大，需要本人签收"
5. AI: "好的，我已经记录下来了，会转告张先生的"
6. 访客: "谢谢，那我先把包裹放在门口了"

**预期识别结果：**

- 意图类型: `delivery`
- 关键信息: 快递、顺丰、需要本人签收
- 通知内容: "快递员来访，顺丰快递送达，包裹需要本人签收"

### 场景2: 朋友拜访

**对话流程：**

1. AI: "您好，请问您找谁？"
2. 访客: "你好，我是李明，来找张伟的"
3. AI: "好的，请问您和张伟是什么关系呢？"
4. 访客: "我们是大学同学，约好今天一起吃饭"
5. AI: "明白了，我帮您通知一下张伟"
6. 访客: "好的，谢谢"

**预期识别结果：**

- 意图类型: `visit`
- 关键信息: 李明、大学同学、约好吃饭
- 通知内容: "朋友来访，李明（大学同学）到访"

### 场景3: 推销人员

**对话流程：**

1. AI: "您好，请问您找谁？"
2. 访客: "你好，我是XX保险公司的，想了解一下您家是否需要保险服务"
3. AI: "不好意思，我们暂时不需要"
4. 访客: "没关系，我可以留个联系方式吗？"
5. AI: "抱歉，我们真的不需要"

**预期识别结果：**

- 意图类型: `sales`
- 关键信息: 保险、推销
- 通知内容: "推销人员来访，保险推销"

### 场景4: 物业维修

**对话流程：**

1. AI: "您好，请问您找谁？"
2. 访客: "你好，我是物业的，来检查一下水表"
3. AI: "好的，请稍等，我帮您联系业主"
4. 访客: "好的，麻烦了，我在门口等"

**预期识别结果：**

- 意图类型: `maintenance`
- 关键信息: 物业、检查水表
- 通知内容: "物业人员来访，检查水表"

### 场景5: 紧急求助

**对话流程：**

1. AI: "您好，请问您找谁？"
2. 访客: "你好，我是楼上的邻居，家里水管爆了，水漏到你家了吗？"
3. AI: "这个情况比较紧急，我马上通知业主"
4. 访客: "好的，麻烦快点，我已经关了总阀门"

**预期识别结果：**

- 意图类型: `emergency`
- 关键信息: 邻居、水管爆了、紧急
- 通知内容: "【紧急】邻居求助，楼上水管爆裂"

## 验证要点

### 1. 服务器端日志验证

检查以下关键日志：

```python
# 语音转文字结果
[ASR] 识别结果: "你好，我是快递员"

# LLM意图识别
[VLLM] 分析意图中...
[VLLM] 识别结果: intent_type=delivery

# 意图总结生成
[DoorlockIntentHandler] 生成意图总结
[DoorlockIntentHandler] 意图类型: delivery, 置信度: 0.95

# 通知发送
[NotificationService] 发送App通知成功
```

### 2. 意图识别准确性

验证以下指标：

| 指标           | 说明             | 目标值 |
| -------------- | ---------------- | ------ |
| 意图分类准确率 | 正确识别意图类型 | ≥90%   |
| 关键信息提取   | 提取留言、提醒等 | ≥85%   |
| 响应时间       | 从语音到识别完成 | ≤3秒   |
| 泛化能力       | 处理不同表述方式 | 良好   |

### 3. 小程序通知验证

检查通知内容：

- ✓ 访客类型正确（快递员/朋友/推销等）
- ✓ 关键信息完整（留言、提醒）
- ✓ 时间戳准确
- ✓ 访客照片显示正常

## 常见问题

### Q1: 连接服务器失败

**解决方法：**

1. 检查服务器是否启动
2. 确认服务器地址和端口正确
3. 检查防火墙设置

### Q2: 意图识别不准确

**可能原因：**

1. LLM模型配置不正确
2. 提示词（prompt）需要优化
3. 对话历史不完整

**解决方法：**

- 检查 `config.yaml` 中的 LLM 配置
- 优化意图识别提示词
- 增加对话轮次

### Q3: 未收到小程序通知

**检查项：**

1. 通知服务是否启用
2. 小程序WebSocket连接是否正常
3. 查看服务器通知发送日志

### Q4: 测试脚本报错

**常见错误：**

```python
# 错误1: ModuleNotFoundError
# 解决: 安装依赖
pip install websockets

# 错误2: Connection refused
# 解决: 确保服务器已启动

# 错误3: Timeout
# 解决: 增加超时时间或检查网络
```
