## 文档信息

- **清理日期**：2026-05-10
- **清理原因**：从服务器端插件方案迁移到 ESP32 端 MCP 工具方案

## 清理概述

本地预览功能原本采用**服务器端插件方案**实现，现已迁移到**ESP32 端 MCP 工具方案**。旧方案已被完全清理，以避免架构冲突和功能重复。

## 已删除的文件

### 1. 插件文件

```
main/xiaozhi-server/plugins_func/functions/control_local_preview.py
```

- **功能**：服务器端本地预览控制插件
- **实现方式**：通过 WebSocket 发送自定义 `local_preview` 消息
- **删除原因**：与 MCP 工具方案功能重复

### 2. 响应处理器

```
main/xiaozhi-server/core/handle/textHandler/localPreviewHandler.py
```

- **功能**：处理 ESP32 返回的 `local_preview` 响应
- **实现方式**：将响应缓存到 `conn._local_preview_response`
- **删除原因**：MCP 方案使用标准 MCP 协议，不需要自定义处理器

### 3. 测试文件

```
main/xiaozhi-server/test/test_local_preview.py
```

- **功能**：测试旧的本地预览插件
- **删除原因**：测试的是已废弃的实现

## 新方案说明

### MCP 工具方案

本地预览功能现在通过 **ESP32 端 MCP 工具** 实现：

#### 工具定义

```json
{
  "name": "self.screen.show_camera",
  "description": "Display the camera preview on the device screen in real-time...",
  "inputSchema": {
    "type": "object",
    "properties": {
      "action": {
        "type": "string",
        "enum": ["start", "stop"]
      }
    },
    "required": ["action"]
  }
}
```

#### 工作流程

```
用户语音："打开监控模式"
    ↓
ASR 识别 → LLM 意图识别
    ↓
LLM 调用 MCP 工具：self_screen_show_camera
    ↓
服务器发送 MCP 调用请求到 ESP32
    ↓
ESP32 在本地屏幕显示摄像头画面
    ↓
ESP32 返回 MCP 响应
    ↓
服务器生成语音反馈："已打开本地预览"
```

#### 服务器端处理

- **完全不需要修改服务器端代码**
- 工具自动注册到 `MCPClient`
- 统一工具管理器自动识别和调用
- 标准 MCP 协议处理响应

## 新旧方案对比

| 特性           | 旧方案（服务器端插件） | 新方案（ESP32 端 MCP 工具） |
| -------------- | ---------------------- | --------------------------- |
| **实现位置**   | 服务器端               | ESP32 端                    |
| **协议**       | 自定义 WebSocket 消息  | 标准 MCP 协议               |
| **配置**       | 需要在服务器配置       | 自动发现，零配置            |
| **扩展性**     | 每次新增需修改服务器   | 只需修改 ESP32              |
| **架构清晰度** | 设备功能在服务器实现   | 设备功能在设备实现          |
| **维护成本**   | 需要同步维护两端       | 只需维护 ESP32              |
| **部署复杂度** | 需要重启服务器         | 只需更新 ESP32 固件         |

## 迁移影响

### ✅ 无影响的部分

1. **用户体验**
   - 语音触发词保持不变
   - 功能行为完全一致
   - 语音反馈保持一致

2. **其他功能**
   - 不影响其他插件和处理器
   - 不影响其他 MCP 工具
   - 不影响 WebSocket 通信

### ⚠️ 需要注意的部分

1. **ESP32 固件要求**
   - ESP32 必须实现 `self.screen.show_camera` MCP 工具
   - 固件版本需要支持 MCP 协议

2. **兼容性**
   - 旧版本 ESP32 固件（未实现 MCP 工具）将无法使用本地预览功能
   - 建议用户升级到最新固件
