## 🚀 快速开始

### 1. 启动服务器

```bash
cd main/xiaozhi-server
python app.py
```

等待看到以下输出：

```
Websocket地址是    ws://192.168.x.x:8000/xiaozhi/v1/
```

### 2. 运行测试（Windows）

双击运行：

```
test/run_intent_test.bat
```

或者命令行：

```bash
cd test
python test_visitor_intent_recognition.py
```

### 3. 查看结果

- **服务器日志**: 查看终端输出
- **测试报告**: `test/test_results/` 目录
- **小程序通知**: 在小程序端查看

## 📝 测试步骤

### 步骤1: 环境准备

```bash
# 1. 安装依赖
pip install websockets

# 2. 检查服务器配置
# 确保 config.yaml 中配置了：
# - LLM (如 ChatGLMLLM)
# - VLLM (如 ChatGLMVLLM)
# - Intent: function_call

# 3. 启动服务器
cd main/xiaozhi-server
python app.py
```

### 步骤2: 运行测试

#### 方式1: 使用批处理脚本（推荐）

```bash
cd test
run_intent_test.bat
```

选择测试模式：

- `1` - 快速测试（单个场景）
- `2` - 完整测试（所有场景）
- `3` - 自定义场景测试

#### 方式2: 直接运行Python脚本

```bash
# 运行所有场景
python test_visitor_intent_recognition.py

# 运行单个场景
python test_visitor_intent_recognition.py --scenario "快递员送货"

# 指定服务器地址
python test_visitor_intent_recognition.py --server ws://192.168.1.100:8000/xiaozhi/v1/
```

### 步骤3: 观察测试过程

测试脚本会输出：

```
==============================================================

==============================================================

[访客] 你好，我是快递员，有个包裹要送给张先生
[AI预期] 好的，请问是什么快递公司的？
[访客] 顺丰快递，麻烦帮我转告一下，包裹比较大，需要本人签收
...
```

### 步骤4: 查看服务器日志

在服务器终端查看关键日志：


## 🔧 常见问题

### Q1: 连接服务器失败

**错误信息：**

```
✗ 连接失败: [Errno 10061] No connection could be made
```

**解决方法：**

1. 检查服务器是否启动

   ```bash
   # 查看进程
   tasklist | findstr python
   ```

2. 检查端口是否被占用

   ```bash
   netstat -ano | findstr 8000
   ```

3. 检查防火墙设置
   - 允许Python通过防火墙
   - 允许端口8000

### Q2: 意图识别不准确

**可能原因：**

1. LLM模型配置不正确
2. 提示词需要优化
3. 对话历史不完整

**解决方法：**

1. 检查LLM配置

   ```yaml
   # config.yaml
   selected_module:
     LLM: ChatGLMLLM
     VLLM: ChatGLMVLLM
     Intent: function_call
   ```

2. 优化提示词
   - 编辑 `doorlock.intent_recognition.prompt`
   - 增加更多示例
   - 明确意图分类标准

3. 增加对话轮次
   ```yaml
   doorlock:
     intent_recognition:
       max_dialogue_rounds: 15 # 增加到15轮
   ```

### Q3: 未收到小程序通知

**检查项：**

1. 通知服务是否启用

   ```python
   # 查看日志
   [NotificationService] 发送App通知成功
   ```

2. WebSocket连接是否正常

   ```python
   # 小程序端检查
   wx.onSocketMessage((res) => {
     console.log('收到通知:', res.data)
   })
   ```

3. 查看数据库记录
   ```sql
   SELECT * FROM visitor_intents ORDER BY created_at DESC LIMIT 10;
   ```

### Q4: 测试脚本报错

**错误1: ModuleNotFoundError**

```python
ModuleNotFoundError: No module named 'websockets'
```

**解决：**

```bash
pip install websockets
```

**错误2: Connection timeout**

```python
asyncio.TimeoutError: 等待超时（10秒）
```

**解决：**

- 增加超时时间
- 检查网络连接
- 确认服务器响应正常

**错误3: JSON decode error**

```python
json.decoder.JSONDecodeError: Expecting value
```

**解决：**

- 检查服务器返回的消息格式
- 查看服务器日志确认错误
- 更新测试脚本以匹配协议
