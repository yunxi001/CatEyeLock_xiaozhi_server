### ✅ 阶段 3：添加错误码验证（已完成）

#### 3.1 server_ack 错误码验证

**文件**：`main/xiaozhi-server/core/app_connection.py`

**修改内容**：

在 `_send_server_ack` 方法中添加错误码范围验证：

```python
from core.constants.error_codes import is_valid_error_code

# 验证错误码范围
if not is_valid_error_code(code):
    self.logger.bind(tag=TAG).warning(
        f"server_ack 错误码超出范围: seq_id={seq_id}, code={code}，"
        f"错误码应在 0-10 范围内"
    )
```

**功能**：

- 检查错误码是否在 0-10 范围内
- 超出范围时记录警告日志
- 不阻止消息发送（向后兼容）
