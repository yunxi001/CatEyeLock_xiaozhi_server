## 🎯 新方案说明

### MCP 工具方案特点

✅ **零配置**：ESP32 连接时自动注册工具  
✅ **自动发现**：LLM 自动识别新工具  
✅ **架构清晰**：设备功能在设备端实现  
✅ **易于扩展**：新增功能只需修改 ESP32  
✅ **标准协议**：使用标准 MCP 协议

### 工具定义

**工具名称**：`self.screen.show_camera`

**触发词**：

- 启动：`打开监控模式`、`显示监控画面`、`打开本地预览`
- 停止：`关闭监控模式`、`关闭监控画面`、`关闭本地预览`

**参数**：

```json
{
  "action": "start" | "stop"
}
```
