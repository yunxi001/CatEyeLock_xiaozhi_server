## 🎯 核心变更

### server_ack 错误码简化

**修改前（v2.3）**：

```
0: 成功
1: 设备离线
2: 参数错误
3: 未认证
4: 内部错误
5: 重复消息
```

**修改后（v2.4）**：

```
0: 成功
3: 参数错误
8: 未认证
9: 重复消息
```

### 设计原则

1. **server_ack 只用于接收确认**：不涉及业务逻辑
2. **业务错误在业务响应中返回**：使用完整的 0-10 错误码
3. **统一错误码体系**：所有错误响应使用 0-10 错误码

## 🔍 验证要点

### 功能验证

- server_ack 返回 code=0（成功）或 code=9（重复消息）
- 超出范围的错误码会记录警告日志
- 业务错误在业务响应中返回（使用完整的 0-10 错误码）

- App 客户端：无影响（错误码范围扩大）
