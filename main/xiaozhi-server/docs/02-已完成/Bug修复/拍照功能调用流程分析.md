## 错误原因分析

### ASCII编码错误位置

错误发生在 `core.providers.llm.openai.openai.py` 的 `response_with_functions()` 方法中。

**可能的原因**：

1. OpenAI SDK内部在处理tool_calls时使用了ASCII编码
2. 某个中间环节没有正确处理中文字符
3. 日志记录或字符串格式化时使用了ASCII编码

### 关键代码位置

`openai.py` 第119-133行：

```python
stream = self.client.chat.completions.create(**request_params)

for chunk in stream:
    if getattr(chunk, "choices", None):
        delta = chunk.choices[0].delta
        content = getattr(delta, "content", "")
        tool_calls = getattr(delta, "tool_calls", None)
        yield content, tool_calls  # ← 这里yield的tool_calls可能包含中文
```

错误捕获位置（第135-137行）：

```python
except Exception as e:
    logger.bind(tag=TAG).error(f"Error in function call streaming: {e}")
    yield f"【OpenAI服务响应异常: {e}】", None
```

### 结论

**没有直接的智能门锁相关插件**，包括：

- ❌ 没有拍照功能插件（take_photo、camera等）
- ❌ 没有门锁控制插件（doorlock、lock、unlock等）
- ❌ 没有访客管理插件

### 可能的情况

1. **拍照功能可能通过以下方式实现**：
   - Device IoT工具（设备端注册的IoT工具）
   - Device MCP工具（设备端MCP服务器）
   - MCP Endpoint（外部MCP接入点）

2. **需要检查的位置**：
   - 设备端是否注册了拍照相关的IoT工具描述符
   - 是否有外部MCP服务提供拍照功能
   - Home Assistant集成中是否有相机实体
