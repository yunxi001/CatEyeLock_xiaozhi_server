## 🎯 功能概述

本地预览功能允许用户在APP端实时查看ESP32设备采集的视频流，主要特性：

- **实时预览**：低延迟的视频流传输
- **多种方案**：支持直连、MCP等多种实现方式
- **前后端协同**：服务器端与APP端紧密配合
- **易于集成**：提供完整的实施指南
