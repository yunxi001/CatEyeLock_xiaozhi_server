## 测试方法

### 模拟策略

1. **VLLM提供者模拟**: 使用AsyncMock模拟VLLM的analyze_unified、final_package_check、generate_intent_summary方法
2. **会话管理器模拟**: 模拟对话历史管理和对话结束检查
3. **照片缓存模拟**: 使用patch模拟PhotoCacheManager的行为
4. **辅助方法模拟**: 模拟拍照、播放语音、保存记录等辅助方法

### 验证方法

1. **方法调用验证**: 使用assert_called、assert_called_once等验证方法是否被正确调用
2. **参数验证**: 检查方法调用时传入的参数是否正确
3. **返回值验证**: 验证方法返回的结果结构和内容是否符合预期
4. **日志验证**: 通过日志输出验证关键流程是否执行

## 发现的问题

### 已解决问题

1. **照片缓存类型问题**:
   - 问题: get_latest_photo返回字符串而不是bytes
   - 解决: 修改mock返回bytes类型

2. **返回值结构问题**:
   - 问题: start_unified_dialogue不返回package_check_result
   - 解决: 调整测试验证逻辑，验证intent_summary结构

3. **基准图片传递问题**:
   - 问题: 后续轮次仍传入baseline_image参数
   - 解决: 通过is_first_round标志控制是否使用基准图片
