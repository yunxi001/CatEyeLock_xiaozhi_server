# 数据库对象修复说明

**日期**: 2026-05-09 19:08  
**问题**: 查询处理器使用了错误的数据库对象

---

## 问题分析

### 错误日志

```
ERROR-'Database' object has no attribute 'get_visitor_intents'
ERROR-'Database' object has no attribute 'get_package_alerts'
```

### 根本原因

`queryHandler.py` 中的 `_get_database()` 函数返回的是 `Database` 对象（旧的数据库类），而不是 `DoorlockDatabase` 对象。

`get_visitor_intents` 和 `get_package_alerts` 方法是在 `DoorlockDatabase` 类中定义的，不在 `Database` 类中。

### 代码问题

**修改前**：

```python
def _get_database(conn):
    try:
        face_service = get_face_service(conn.logger)
        return face_service.db  # 返回的是 Database 对象
    except Exception as e:
        return None
```

**问题**：`face_service.db` 是旧的 `Database` 对象，没有门锁相关的方法。

---

## 修复方案

### 修改内容

**文件**: `main/xiaozhi-server/core/handle/textHandler/queryHandler.py`

**修改后**：

```python
def _get_database(conn):
    """获取数据库实例

    优先从 FaceService 获取 DoorlockDatabase，确保使用同一个数据库连接池
    """
    try:
        face_service = get_face_service(conn.logger)
        # 检查 face_service 是否有 doorlock_db 属性
        if hasattr(face_service, 'doorlock_db'):
            return face_service.doorlock_db

        # 如果没有，尝试创建 DoorlockDatabase 实例
        from core.providers.doorlock.doorlock_database import DoorlockDatabase
        from config.config_loader import load_config

        config = load_config()
        doorlock_db = DoorlockDatabase(config)

        # 缓存到 face_service 中，避免重复创建
        face_service.doorlock_db = doorlock_db

        return doorlock_db
    except Exception as e:
        conn.logger.bind(tag=TAG).error(f"获取数据库实例失败: {e}")
        return None
```

### 修复逻辑

1. **优先使用缓存**：检查 `face_service` 是否已有 `doorlock_db` 属性
2. **懒加载创建**：如果没有，创建新的 `DoorlockDatabase` 实例
3. **缓存实例**：将创建的实例缓存到 `face_service` 中，避免重复创建
4. **返回正确对象**：返回 `DoorlockDatabase` 对象，包含所有门锁相关方法
