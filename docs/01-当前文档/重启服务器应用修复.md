## 重启步骤

### 方法 1: 使用 systemd（推荐）

如果服务器使用 systemd 管理：

```bash
# 重启 Python 服务器
sudo systemctl restart xiaozhi-server

# 查看服务状态
sudo systemctl status xiaozhi-server

# 查看实时日志
sudo journalctl -u xiaozhi-server -f
```

### 方法 2: 手动重启

如果服务器是手动启动的：

```bash
# 1. 进入 conda 环境
conda activate xiaozhi

# 2. 进入服务器目录
cd main/xiaozhi-server

# 3. 停止旧进程（查找进程 ID）
ps aux | grep "python.*app.py"

# 4. 杀死进程（替换 <PID> 为实际进程 ID）
kill <PID>

# 或者强制杀死
kill -9 <PID>

# 5. 启动新进程
python app.py
```

### 方法 3: 使用 Docker（如果适用）

如果服务器运行在 Docker 容器中：

```bash
# 重启容器
docker restart xiaozhi-server

# 查看日志
docker logs -f xiaozhi-server
```
