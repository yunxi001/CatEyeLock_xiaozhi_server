# 智能门锁AI提示词设计总结

## 完成时间

2026-02-09

## 概述

完成了智能门锁AI功能的提示词设计，包括意图识别提示词、看护模式提示词和欢迎词模板。所有提示词已通过完整性和有效性验证。

## 完成内容

### 1. 意图识别提示词 (intent_recognition_prompt)

**包含内容：**

- ✓ 系统角色定义：智能门锁的AI门卫助手
- ✓ 职责说明：识别访客、意图识别对话、看护快递、记录通知
- ✓ 对话风格指南：礼貌正式但亲和、根据访客身份调整语气、对可疑行为警惕
- ✓ 对话策略：主动引导、简洁明了、确认重要信息、礼貌拒绝推销
- ✓ 工具调用说明：5个工具函数的详细使用场景和参数说明
  - enable_package_guard
  - disable_package_guard
  - update_package_baseline
  - report_package_status
  - report_visitor_intent
- ✓ 示例对话：9个场景（快递员、朋友拜访、推销人员等）

**特点：**

- 参考了 agent-base-prompt.txt 的设计风格
- 提供了详细的工具调用场景说明
- 包含完整的参数定义和使用示例
- 对话策略清晰，易于AI理解和执行

### 2. 看护模式提示词 (package_guard_prompt)

**包含内容：**

- ✓ 看护任务说明：对比图片判断异常行为
- ✓ 威胁等级判断标准：
  - 低威胁：路人/主人取件/工作人员
  - 中威胁：长时间停留/翻看快递/多次往返
  - 高威胁：非主人拿走/破坏/撬门/多人可疑
- ✓ 明确主人（is_owner=true）取走快递为低威胁
- ✓ 明确非主人取走快递为高威胁
- ✓ 行为类型定义：taking, searching, damaging, normal, passing
- ✓ 工具调用说明：4个工具函数的详细说明
  - report_package_status
  - update_package_baseline
  - enable_package_guard
  - disable_package_guard
- ✓ 基准图片更新时机：门口物品增多、对话中提到"放这了"
- ✓ 看护模式控制逻辑：主人取走时关闭、访客提到快递时启用
- ✓ 示例场景：8个场景（路人经过、主人取件、陌生人拿走、翻看快递、破坏快递、快递员送货、多次往返）

**特点：**

- 威胁等级判断标准清晰明确
- 特别强调主人和非主人的区别
- 提供了丰富的示例场景覆盖各种情况
- 工具调用时机说明详细

### 3. 欢迎词模板 (welcome_templates)

**包含内容：**

- ✓ 温馨家庭风格（morning, afternoon, evening, night, default）
- ✓ 简洁风格（default）
- ✓ 正式风格（morning, afternoon, evening, night, default）
- ✓ 活泼风格（额外提供）
- ✓ 温暖关怀风格（额外提供）
- ✓ 所有模板都支持 {name} 占位符
- ✓ 所有欢迎词长度 < 20字

**时段划分：**

- morning: 6:00-12:00（早晨）
- afternoon: 12:00-18:00（下午）
- evening: 18:00-22:00（晚上）
- night: 22:00-6:00（夜间）
- default: 未配置对应时段时使用

**特点：**

- 提供了5种不同风格供用户选择
- 欢迎词简洁友好，适合语音播放
- 支持姓名个性化替换
- 包含默认欢迎词作为后备方案
